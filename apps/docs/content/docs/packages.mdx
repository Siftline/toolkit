## `@siftline/core`

The Engine. Recipes, rules, fixtures, the Judge and the Decision format live here. It
exposes two entries: the main one, and `@siftline/core/testing` for the scripted and replay
clients tests judge against.

```ts
import { choice, defineRecipe, noul } from "@siftline/core";

const recipe = defineRecipe({
  name: "support-inbox",
  version: 1,
  model: "jev-1.13.0",
  questions: {
    category: choice("Which category best describes this message?", {
      complaint: "The sender is unhappy with the product or service",
      question: "The sender asks how something works",
      other: "Anything else, including spam and thanks",
    }),
    wants_human: noul("Does the sender ask to speak to a person?"),
  },
});
```

## `@siftline/cli`

Ships the `siftline` bin. `siftline test` measures a Recipe against a JSONL file of
Fixtures; `siftline label` judges real Records and writes one Decision line each.

```bash
npx siftline test recipe.json fixtures.jsonl
```

## `@siftline/actions`

Adapters that carry a Decision somewhere: `webhook` and `slackIncomingWebhook`. `build`
turns a Decision into a request, `perform` sends it with an injected `fetch`.

<Callout>
  All three packages are versioned independently. A change to one does not bump the others beyond
  the internal dependency patch.
</Callout>
